# 🎮 Tank Battle — Raeed Khan

A professional browser-based tank battle game created by **Raeed Khan**.

## 🕹️ About The Game

Tank Battle is a simple action game where the player's tank fights against multiple enemy tanks.

Enemy tanks:

- Move toward the player's tank
- Fire bullets at the player's tank
- Have different colors
- Can be destroyed by the player's bullets
- Become more challenging as the score increases

If an enemy tank collides with the player's tank, the player's health is reduced.

When the player's health reaches zero, the game ends.

---

## 🎮 Controls

| Key | Action |
|---|---|
| ⬅️ Left Arrow | Move tank left |
| ➡️ Right Arrow | Move tank right |
| ⬆️ Up Arrow | Move tank up |
| ⬇️ Down Arrow | Move tank down |
| SPACE | Fire |
| R | Restart after Game Over |
